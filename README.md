# 🎯 Number Guessing Game

A simple and interactive number guessing game built with **HTML**, **CSS**, and **JavaScript**. The game generates a random number between 1 and 10, and the player has three attempts to guess it correctly.

## 💡 Features

- Random number generation on each refresh
- Three chances to guess the number
- Real-time feedback on whether your guess is too high or too low
- Friendly UI with a modern, responsive design
- Clear messaging for win, lose, and invalid input scenarios

## 📁 Project Structure

🖥️ Demo
